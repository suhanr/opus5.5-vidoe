# Font log — The Unsaid

Every episode uses its own set of Lipighor (lipighor.com) fonts. Before starting a new episode, check this list and choose fonts that have not been used yet.
Font files stay out of git (licence); they are kept locally in `the-unsaid/assets/fonts/`.
